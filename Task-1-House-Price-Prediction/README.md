# SkillCraft Technology – Machine Learning Internship

## Task 1: House Price Prediction Using Linear Regression

### Project Overview

This project focuses on predicting house prices using Machine Learning. Linear Regression is used to understand the relationship between house features and their selling prices.

The project demonstrates the basic Machine Learning workflow, including data preprocessing, feature selection, model training, prediction, and model evaluation.

### Objective

The main objectives of this project are:

* To explore and understand house price data.
* To select relevant features for predicting house prices.
* To build a Linear Regression model.
* To evaluate the model's performance using appropriate metrics.
* To visualize the relationship between house features and predicted prices.

### Dataset

The project uses a house price dataset containing information about residential properties.

The dataset may include features such as:

* **GrLivArea:** Above-ground living area.
* **BedroomAbvGr:** Number of bedrooms above ground.
* **FullBath:** Number of full bathrooms.
* **SalePrice:** Selling price of the house, used as the target variable.

### Model Evaluation

The model can be evaluated using the following metrics, if calculated in the notebook:

* **Mean Absolute Error (MAE):** Measures the average absolute difference between actual and predicted prices.
* **Root Mean Squared Error (RMSE):** Measures prediction error while giving more weight to larger errors.
* **R² Score:** Indicates how well the model explains the variation in the target variable.
